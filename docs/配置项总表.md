# 配置项总表

> 本表提取自配置 schema（`_conf_schema.json`，与代码一致）。修改配置项必须同步本表与 schema。
> 末组「高级选项」条目多数为 `invisible`（AstrBot 原生配置页隐藏，仅页面「配置」Tab 可编辑）。

## 基础设置

| 配置项 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `managed_groups` | list | `[]` | 受管群白名单；**留空 = 自动管理机器人所在的所有群** |
| `global_admin_qqs` | list | `[]` | 全局管理员 QQ（凭据类，不落文档/日志） |
| `auto_index_upload_event` | bool | `true` | 监听 group_upload 事件索引 |
| `auto_scan_interval_hours` | float | `6` | 目录级差分对账周期（小时；0=关闭定时对账，仍可手动触发；云端缺席的群冻结保护、不误删） |
| `group_info_ttl_hours` | float | `24` | 群信息有效期（小时），到期自动重扫保持容量/相册/精华计数最新；0=关闭过期重扫 |
| `auto_label` | bool | `true` | 自动为群分配编号（便于面板排序） |
| `page_size` | int | `10` | 管理面板文件列表每页条数（1-100，页面可临时切换） |
| `request_interval` | float | `1.0` | QQ 接口调用基础间隔（秒；读类接口自动放宽到 0.4 倍）。旧毫秒键 `request_interval_ms`（默认 1000）仅在秒键未设置时生效，为兼容保留 |

## 自动保存与分卷

| 配置项 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `fetch_max_size` | string | `'2GB'` | URL 拉取单文件上限（带单位大小；含桥接回退分支硬限） |
| `fetch_timeout_sec` | int | `180` | URL 拉取超时（秒） |
| `fetch_allow_private_address` | bool | `false` | 允许 fetch 拉取内网地址（SSRF 显式开关） |
| `essence_chunk_size` | int | `4000` | 长文本保存为精华消息的分段长度（QQ 单条 4000 字符硬限制；分片含语义化标记仍不超限） |
| `video_segment_seconds` | int | `599` | 长视频导入相册的切分时长上限（QQ 相册 599 秒硬限制） |
| `volume_threshold` | string | `'95MB'` | 文件分卷阈值（带单位大小；超过自动分卷压缩上传） |

## 下载服务

| 配置项 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `download_server_enabled` | bool | `false` | 启用（桥接正向与外部下载依赖） |
| `download_server_host` | string | `127.0.0.1` | 对外地址（**必须从 OpenList 侧可达**：容器部署时 127.0.0.1 会使 bridge_out 离线下载失败 `dial tcp 127.0.0.1:6186: connect refused`，须改为 OpenList 容器内可解析的地址如宿主容器名 `astrbot`） |
| `download_http_port` | int | `6186` | HTTP 下载端口 |
| `download_sftp_port` | int | `0` | SFTP 端口（0=关闭） |
| `download_smb_port` | int | `0` | SMB 端口（0=关闭；需可选依赖 impacket，共享名 cloud，内容按需落盘） |
| `download_token` | string | `''` | 下载令牌（凭据类）。**留空时下载服务 fail-closed：直链与外部下载一律拒绝**，需显式配置后可用 |
| `download_cache_max_mb` | int | `1024` | 下载服务本地缓存容量上限（MB，0 = 不限）。超出时按**最久未使用**逐出 |
| `download_cache_ttl_hours` | int | `24` | 缓存文件闲置多久后可清理（小时，0 = 不按时间清理） |

| `type_ext_overrides` | dict | `{}` | 扩展名→类型分类覆盖（影响后续登记/展示，不改已登记行）；分类为 13 类机器值（document/pdf/spreadsheet/slide/online_doc/image/video/audio/archive/installer/flash/folder/other），后缀编辑即由此配置项承担 |
| `preview_policy` | dict | `{}` | 预览策略覆盖（mode: builtin/external/download + 外链模板 `{src}`） |
| `database_admin_token` | string | `''` | 数据库管理接口独立令牌（凭据类；**留空=所有 database/* 操作一律拒绝**，不做面板权限回退——恢复属破坏性操作，须显式配置第二信任层） |

> **13 类分类**：分类表定义于核心域文件类型模块
> （中文显示由前端字典承担）；`program→installer`、`data→other` 为历史值映射；目录行
> 恒为 `folder` 类；预览策略默认表按分类组同步。chips 顺序：
> 全部/文稿/PDF/表格/幻灯片/在线文档/图片/视频/音频/压缩包/安装包/闪传文件/文件夹/其他。

> 配置中心分组元数据内建于配置 schema（`"group"` 字段，5 组：基础设置 /
> 自动保存与分卷 / 下载服务 / 网盘归档 / 高级选项，组序即渲染序，高级组在 AstrBot
> 原生配置页隐藏）；`config/get`（分组 + 敏感脱敏 *** + reload_required 标记）+
> `config/save`（类型归一 + 持久化）+ `config/reload`（热重载）。

## 使用要点

- **配置唯一权威入口**：Config Tab（`config/get` + `config/save` + `config/reload`）。
  所有配置项的新增、修改、删除**必须**通过此入口；其他位置的配置编辑能力仅为便捷快捷方式。
- **历史双入口**：`bridge/config/save` 与 `config/save` 写同一份配置文件，
  前者仅 Bridge Panel 的「配置」按钮使用（5 项连接字段）。**新功能禁止使用 `bridge/config/save`**，
  统一走 `config/save`；该端点保留仅为向后兼容。
- 配置存放：AstrBot `data/config/`（仪表盘插件配置页编辑）；
  全部配置项可经页面「配置」Tab 在线编辑保存（`config/get` + `config/save`）。
- **降级开关**（故障隔离）：`openlist_enabled=false`、
  `download_server_enabled=false`、`auto_scan_interval_hours=0`。


## 配置生效语义（哪些键需要重载）

`config/save` 会写盘并更新 `s.config` 的内存值，但**有些键在服务构造时就被复制进长生命周期
对象**，只改 `s.config` 到不了运行中的服务。这类键由后端在响应里回 `reload_required` 列表，
前端弹「以下配置需重载插件后生效：… 立即热重载？」确认框
（`pages/storage-ng/views/config.js`）。

**单一事实源**：`webapi/config.py` 的 `_RELOAD_REQUIRED_KEYS`。
`config/get`（给字段打「需重载」角标）与 `config/save`（决定是否弹框）都读它。
**新增一个构造期固化的键时，必须同时加进这个集合** —— 漏了不会报错，只会静默不生效。

| 键 | 固化位置 |
| --- | --- |
| `managed_groups`、`global_admin_qqs` | `PermissionService.__init__` → `self._managed` / `self._admins`（`set` 副本） |
| `request_interval` | `KeyedLimiter`：某账号的 interval 在**首次 `acquire()`** 时固化，改配置对已用过的账号无效 |
| `download_server_enabled` / `download_server_host` / `download_http_port` / `download_sftp_port` / `download_smb_port` / `download_token` / `download_cache_max_mb` / `download_cache_ttl_hours` / `fetch_allow_private_address` | `DownloadServerService.__init__` → `self.enabled` / `host` / 三个 port / `token` / `allow_private` / `cache_max_bytes` / `cache_ttl_seconds`。`download_token` 还参与每条 http / sftp / smb 地址的鉴权；两个 cache 键由 `download_cache.sweep_cache` 消费 |
| `openlist_enabled` / `openlist_base_url` / `openlist_username` / `openlist_password` / `openlist_token` / `openlist_timeout_sec` / `openlist_allow_private_address` | `OpenListClient.__init__` → `self._base_url` / `_token` / `_timeout` / `_allow_private` |

其余键（`volume_threshold`、`page_size`、`auto_*`、`essence_chunk_size` 等）在调用点按次读取，
**保存即生效**，不出现在 `reload_required` 里。

## 已废弃别名（兼容保留，勿在新部署中使用）
