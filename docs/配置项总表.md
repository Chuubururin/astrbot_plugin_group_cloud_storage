# 配置项总表

> 本表提取自配置 schema（与代码一致）。修改配置项必须同步本表与 schema。

## 群与权限

| 配置项 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `managed_groups` | list | `[]` | 受管群白名单；**留空 = 全部已发现群可管理** |
| `global_admin_qqs` | list | `[]` | 跨群全局管理员 QQ（凭据类，不落文档/日志） |

## 调度与风控

| 配置项 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `request_interval_ms` | int | `1000` | OneBot 扩展 API 最小间隔（配置下限 100） |
| `auto_scan_interval_hours` | float | `6` | 差分对账周期（小时；0=关闭周期差分，仅事件驱动新增 + 手动全量） |
| `auto_index_upload_event` | bool | `true` | 监听 group_upload 事件索引 |
| `op_high_priority_kinds` | list | `[]` | OpQueue 优先级 kind 覆盖（空=内置默认） |

## 列表与展示

| 配置项 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `page_size` | int | `10` | 文件列表默认每页条数 |
| `auto_label` | bool | `true` | 自动打标 |

## 入库与拆分

| 配置项 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `essence_chunk_size` | int | `4000` | 精华单条字符上限（QQ 实限 4500，预留语义化标记预算，默认 4000） |
| `video_segment_seconds` | int | `599` | 相册视频分段上限（≥599s 切为 <599s 段，默认 599） |
| `fetch_max_bytes` | int | `2147483648`（2GB） | URL 拉取单文件上限（含桥接回退分支硬限） |
| `fetch_timeout_sec` | int | `180` | URL 拉取超时（秒） |

## 本机下载服务

| 配置项 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `download_server_enabled` | bool | `false` | 启用（桥接正向与外部下载依赖） |
| `download_server_host` | string | `127.0.0.1` | 对外地址（**必须从 OpenList 侧可达**：容器部署时 127.0.0.1 会使 bridge_out 离线下载失败 `dial tcp 127.0.0.1:6186: connect refused`，须改为 OpenList 容器内可解析的地址如宿主容器名 `astrbot`） |
| `download_http_port` | int | `6186` | HTTP 下载端口 |
| `download_sftp_port` | int | `0` | SFTP 端口（0=关闭） |
| `download_smb_port` | int | `0` | SMB 端口（0=关闭；需安装 impacket） |
| `download_token` | string | `''` | 下载令牌（凭据类） |

## OpenList 桥接

| 配置项 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `openlist_enabled` | bool | `false` | 启用桥接（故障隔离总开关） |
| `openlist_base_url` | string | `''` | OpenList 地址 |
| `openlist_username` / `openlist_password` | string | `''` | 登录凭据 |
| `openlist_token` | string | `''` | Token 直接注入（优先于用户名密码） |
| `openlist_dst_dir` | string | `/` | 转存目标根目录 |
| `openlist_dst_dir_template` | string | `{group_id}/{filename}` | 路径模板（字面替换） |
| `openlist_timeout_sec` | float | `30` | API 超时（秒） |
| `openlist_allow_private_address` | bool | `false` | 内网/环回放行（SSRF 显式开关） |
| `openlist_poll_interval_sec` | int | `0` | 轮询间隔（0=手动；>0 任务驱动、清零自停） |
| `bridge_min_bytes` / `bridge_max_bytes` | int | `0` | 转存大小窗口（0=不限） |

## 分类与预览

| 配置项 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `type_ext_overrides` | dict | `{}` | 扩展名→类型分类覆盖（影响后续登记/展示，不改已登记行）；分类为 13 类机器值（document/pdf/spreadsheet/slide/online_doc/image/video/audio/archive/installer/flash/folder/other），后缀编辑即由此配置项承担 |
| `preview_policy` | dict | `{}` | 预览策略覆盖（mode: builtin/external/download + 外链模板 `{src}`） |

> **13 类分类**：分类表定义于核心域文件类型模块
> （中文显示由前端字典承担）；`program→installer`、`data→other` 为历史值映射；目录行
> 恒为 `folder` 类；预览策略默认表按分类组同步。chips 顺序：
> 全部/文稿/PDF/表格/幻灯片/在线文档/图片/视频/音频/压缩包/安装包/闪传文件/文件夹/其他。

## 调试工作台

| 配置项 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `debug_workbench_enabled` | bool | `false` | 调试工作台开关（三栏：操作构建器/API 浏览器/调试日志；默认关闭；仅 GLOBAL_ADMIN 语义） |

> 配置中心分组元数据已内建于配置 schema（`"group"` 字段，8 组：同步与凋零 / 入库与
> 组合存储 / 桥接与网盘 / 下载服务 / 任务与队列 / 页面与预览 / 权限与发布 / 调试）；
> `config/get`（分组 + 敏感脱敏 ***）+ `config/save`（类型归一 + 持久化 + 重载提示）。

## 使用要点

- 配置存放：AstrBot `data/config/`（仪表盘插件配置页编辑）；桥接六项可经页面
  「网盘→设置」在线保存（`bridge/config/save`，密码脱敏返回 ***，保存即生效）；
  全部配置项可经页面「配置」Tab 在线编辑保存（`config/get` + `config/save`）。
- **降级开关**（故障隔离）：`openlist_enabled=false`、
  `download_server_enabled=false`、`auto_scan_interval_hours=0`。
