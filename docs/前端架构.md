# 前端架构（pages/storage-ng）

> 插件 Page 前端的技术架构。以**操作规格矩阵**为纲领，支撑机制是实现这些规格的技术底座。

## 技术栈与硬约束

- **零构建**：原生 ESM + Web Components，无框架、无打包链、无 vendored 运行时；
  页面由宿主 Page Bridge SDK 加载（postMessage 传输 + 宿主 JWT 鉴权）。
- **单文件 ≤300 行**（结构预算机检自动守门）。
- **零 emoji**：图标唯一来源图标常量模块。
- **机器值 + 前端字典**：API 返回 type/state 等机器值，中文显示由字典模块承担。
- API 路径只走 API 常量表，禁止拼字符串；桥接调用走 SDK
  `bridge.*`（subscribeSSE/download 等），不使用原生 EventSource。
- **模块预加载**：沙箱 iframe 拿不到宿主 cookie，URL 里的 asset_token 约 60 秒过期；
  主入口初始化时并行预加载全部视图模块（各取第一个 import thunk），之后点任何标签
  都不再发模块请求；重载恢复前本地解析 token 的 exp，已过期则提示刷新宿主页面而非
  执行注定 401 的整页 reload。

## 操作规格矩阵

> 每格：「入口（命令/按钮）→ 端点」。smb 直链需安装 impacket 且配置 `download_smb_port`（未安装时诚实降级）；跨 Tab 上传来源=**真选择器**（cross-upload）。

### 群文件 Tab

| 操作 | 规格 | 入口与端点 |
| --- | --- | --- |
| 上传 | 本地 | toolbar「上传」→ `ingest.showUploadSourceModal` 来源分段（默认本地）→ prepare/upload 两段式（`files/upload/prepare`+`files/upload`；批量命名/视频文本入库模态/convert_to/有损选项） |
| 上传 | URL 链接 | 来源分段「URL 链接」→ `fetch`（含 convert_to 选项） |
| 上传 | 文本 | 来源分段「从浏览器上传文本」→ 文本入库模态（存精华或存文件） |
| 上传 | 由网盘 | 来源分段「由网盘上传」→ **pickNetdiskFile 选择器** → `netdisk/distribute` target=group（真操作，非引导） |
| 上传 | 由相册 / 由精华 | 来源分段「由相册/由精华上传」→ **pickCloudResource('album'/'essence') 选择器** → `albums/distribute` / `essence/distribute` target=group |
| 刷新 | 所有 | 刷新菜单「全量刷新」→ `groups/scan`（含群文件+容量全量） |
| 刷新 | 当前选中群 | 「文件刷新（当前群）」→ `files/scan {mode:'range', group_ids:[g]}`（契约用法） |

| 筛选 | 类型 / 状态 | `files?type=` / `files?status=`（netdisk/album/essence/none 派生投影） |

## 支撑机制

### 命令层与动作栏

- **声明式命令注册表**（command-registry + 各域命令定义）：`{id, label, danger, needsSingle,
  needsGroup, confirm?, run(ctx), refresh?}`；能力矩阵（capability）→ 命令映射即按钮渲染；
- **统一生命周期** `runCommand`：`canRun 前置校验 → confirm 门禁 → busy → run → toast →
  refresh → clear`；错误包络；busy 态防重入；
- **行感知 group**（聚合视图）：操作以行内 group_id 为上下文；
- **四源选择集独立**：状态选择模块 `selectionFor(key)` 工厂——file/album/essence/
  netdisk 各自独立选择集；
- stale-response 防护（reqSeq/isStale）、键盘无障碍（Esc 清当前源选择 / Ctrl+A 全选 /
  模态焦点还原）、行内右键菜单（context-menu）。

### 四数据源适配器

数据源适配模块四源（GROUP/NETDISK/ALBUM/ESSENCE）：一套数据表格 + 一套
动作栏服务四个 Tab；相册/精华持独立分页（albumPage/essencePage）+ 群聚焦 + 查询词
+ 标签筛选（模块隔离）；网盘本地过滤/排序（applyLocalFilterSort + netdiskType 隔离）。

### 状态与刷新唯一化

状态只经状态容器 get/set/subscribe；刷新只经统一主题
（DATA_CHANGED_TOPICS：scan/groups、file_scan/files、upload/files、essence_save/essence
等 kind→主题映射）；SSE 重连后全主题刷新，同主题 150ms 窗口内刷新合并防请求风暴。

### keyed DOM diff

DOM 差分模块：顺序保持键控协调 + rAF 分帧（≤50 行/帧）；数据表格四源共用一套渲染（含 `../` 上一级、目录行、分卷/长集徽标）。

### SSE 统一管线与心跳自愈

SSE 模块：30s 心跳、90s 无事件判断线、指数退避重连（1s→30s）、重连后全主题刷新；
定时参数可注入。

### 上传/入库管线

上传模块（两段式核心 + resolveUploadGroup 推荐群）→ 入库模块（来源
模态：文件六源/相册三源/精华四源；convert_to 与有损选项全面贯通）→
跨源选择器（跨源真选择器，复用转存端点，零新端点）→
网盘上传模块（本地→群→网盘两步接力，可测核心）。

### 其他

分类/预览数据驱动（meta/classify + preview/policy）、框选（marquee-select）、
主题跟随、缺省规则（created_at desc/单栏/最小群号+容量预检 size 参数）、集语义、
任务四动作与操作流、配置中心（5 组分组渲染 + 搜索 + 敏感脱敏）。
