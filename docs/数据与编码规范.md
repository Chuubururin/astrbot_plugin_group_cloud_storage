# 数据与编码规范

> 存储：**独立 SQLite**（`data/plugin_data/group_cloud_storage/meta.db`，`PRAGMA journal_mode=WAL`，`foreign_keys=ON`）。

## 资源统一编码

### 资源 URI（稳定引用）

```
cloud://<group_id>/<type>/<id>
  例：cloud://1044426419/file/432
      cloud://1044426419/album/129
      cloud://1044426419/essence/186
```

- `group_id`：QQ 群号（字符串，全数字）；`type`：`file` | `album` | `essence`（机器值）
- `id`：本地索引主键（resources.id，稳定；跨群唯一）
- 解析接口：`GET /files/uri?uri=cloud://...` → 资源行
- 网盘侧**不适用**本 URI（网盘用 `remote_path` 稳定引用：不引入第二 URI 方案）

### 资源逻辑路径（文件系统化寻址）

| type | path 规则 | 示例 |
| --- | --- | --- |
| file | `/<group_id>/<folder_name>/<name>`（无目录时省略 folder） | `/1044426419/资料/a.pdf` |
| album | `/<group_id>/__album__/<相册名>` | `/1044426419/__album__/相册名测试` |
| essence | `/<group_id>/__essence__/<标题>` | `/1044426419/__essence__/长文归档` |

`resources.path` + `(group_id, path)` 索引，可按前缀检索；`ext`：file=小写扩展名（无点），
album/essence 恒为 `album`/`essence`。

### meta JSON 规范化（snake_case，程序可解析）

```jsonc
{
  "summary": "精华/相册描述摘要（≤200字）",
  "kind": "bytes | video | text_split",
  "volumes": true,                                // 兼容形态标记（读侧识别）
  "total_sha256": "hex", "total_seconds": 605.0,
  "composition": {"kind": "volumes", "parts": 3, "strategy": "binary",
                   "total_sha256": "...", "marker": null},
  "parts": [{"seq": 1, "message_id": "383…", "chars": 4000}],
  "album_id": "V61…", "desc": "…", "upload_number": 3
}
```

约定：全部键 snake_case；`parts[]` 有序；缺失键按类型默认值处理。

> 精华分片阈值 **4000 字符**（QQ 实限 4500，预留语义化标记预算）；
> 分片优先级：段落 → 标题 → 汉字序号 → 兜底硬切。

## 迁移框架

- `_MIGRATIONS: dict[int, list[str]]`：启动读 `schema_version`，**仅执行增量版本**
  （ALTER 等非幂等语句安全），完成后 `INSERT OR REPLACE` 写目标版本。
- 回滚语义：迁移只前进；回滚 = 还原库文件快照 + 回退代码。

## 核心表结构

### `resources`

| 列 | 类型 | 说明 |
| --- | --- | --- |
| `id` | INTEGER PK AUTOINCREMENT | 内部主键；`/csfile <id>` 与 `cloud://…/<id>` 指此值 |
| `resource_id` | TEXT UNIQUE NOT NULL | `{group_id}:{type}:{source_ref}` 幂等唯一键 |
| `group_id` / `type` / `name` / `size` | — | type 为机器值 file/album/essence |
| `sha256` / `mime` | TEXT 可空 | 预留（sha256 供分卷校验） |
| `uploader_id`（idx）/ `uploader_name` | TEXT | 上传者（事件保证字段 + source-enriched） |
| `source_ref` / `busid` | — | file_id / msg_seq / album_id；下载删除所需 |
| `folder_id`（idx）/ `folder_name` | TEXT | 所属目录 |
| `path` / `ext` | TEXT NOT NULL 默认 '' | 文件系统化路径（idx_res_group_path） |
| `status` | TEXT 默认 active | active/archived/deleted（软删除；**桥接状态禁写本列**） |
| `tags` / `meta` | TEXT JSON | 标签数组 / meta JSON 规范化 |
| `created_at` / `indexed_at` / `updated_at` | INTEGER | 源侧 / 入库 / 更新 |

索引：`UNIQUE(resource_id)`、`idx_res_group_type_status`、`idx_res_folder`、
`idx_res_uploader`、`idx_res_name`、`idx_res_group_path`。

### `groups`

`group_id` PK、group_name、join_time、last_sync_at、sync_cursor、role、display_name、sort_order、label、last_scan_at、used_space、total_space、file_count、managed（0=已移除，扫描不复活，白名单优先复活）、album_count、essence_count、account_id（多账号归属）。

> **在线账号**的群组信息才符合要求；账号离线/更换 → 该账号群组**隐藏**
> （非删除，凋零）；隐藏语义由 `groups.hidden` 列承载。

### `volumes` 与 `folders`

- volumes：`parent_resource_id`+`seq` UNIQUE、`part_name`、`size`、`sha256`、
  `status`（pending→uploaded，断点续传持久进度依据）、`group_id`（跨群分卷）。
- folders：`group_id`+`folder_id` UNIQUE、`folder_name`、`parent_id`、`sort_order`。

### `snapshots` / `sync_logs`（只追加）

- snapshots：group_id+type+taken_at；file_count/total_size/used_space/total_space/detail(JSON)。
- sync_logs：id（任务号）、kind、status（running/ok/failed/cancelled）、files_found/files_indexed、
  **complete**（孤儿清理门控）、error、start_at/end_at。

### `archive_map`

```sql
PRIMARY KEY (resource_id, group_id, direction)  -- remote_path 完成后重命名，不入主键
-- 列：resource_id, group_id, task_id, remote_path, direction(out|in),
--    state(pending|running|done|failed|unknown 机器值), updated_at
```

state 只存本表，禁写 resources.status；不存 URL；
单任务查询 `get_archive_map_by_task`；僵尸 pending_in 启动收敛为 failed；done 行 stat 探活后可重提。

### `netdisk_meta`

`remote_path` PRIMARY KEY；name/is_dir/size/type（分类机器值）/tags/registered_at/indexed_at。
登记 = `INSERT OR IGNORE`（不覆盖人工标注）；深度索引 = 手动任务 kind=`netdisk_index`。

### `resources_fts` 与 `v_resources`

- FTS5 索引 `name/summary/tags/groupname/path/folder/mime/uploader/hash/groupid`，使用 trigram；资源增删改由三触发器同步。
- 检索 FTS bm25 优先，短词回退 LIKE，并覆盖路径、文件夹、MIME、上传者、哈希、来源和群号。
- `v_resources`：拼好 `cloud://…` uri 的可读视图（程序化查询面）。

### `netdisk_meta_fts`

FTS5 trigram 本地索引，覆盖 `netdisk_meta` 的 `name`、`remote_path`、`tags`、`type`。网盘搜索只检索已登记的本地索引；不带查询词时仍从 OpenList 实时浏览当前目录。

> **分类 13 类机器值**：`document/pdf/spreadsheet/slide/
> online_doc/image/video/audio/archive/installer/flash/folder/other`（中文显示由前端字典承担）。
> 历史值映射：`program`→`installer`、`data`→`other`；已登记行的 `type` 不重写，展示时
> 按分类默认表实时映射。目录行类别恒为 `folder`，不参与扩展名判定。
>
> **状态派生**：`store_status ∈ netdisk|album|essence|none`
> （在网盘/在相册/在精华消息/未下载）为**查询层派生列**（SELECT 只读，不写库），
> 语义为**交叉存在性判定**（2026-09 修订）——群文件行恒为 `type='file'`，
> 状态筛选回答"该群文件是否同时存在于另一存储"，绝不把相册/精华类型行
> 本身当作筛选结果（那是其他 tab 的列表）：
> 资源 id 关联 archive_map(direction=out, state=done) → netdisk（id 关联优先）；
> 同群同名 album/essence 资源存在（文件名兜底，转存管线保留原文件名）→ album/essence；
> 均不命中 → none。
>
> **集语义**：大文件集（分卷 `meta.volumes`）、长视频集
> （分片语义化标题）、长文本集（末尾语义化标记 `meta.parts`）为**逻辑资源**；列表按逻辑
> 资源呈现，重组经下载后按语义化标识完成。

### `fts_state` 与异步索引

`fts_state.mode` 为 `sync` 或 `async` 的实际运行状态。同步模式由 FTS 触发器即时维护；异步模式仅写入 `fts_dirty_queue`，由后台 worker 批量重建，搜索允许短暂最终一致。`set_fts_mode()` 会先从 `resources` 全量重建并清理 dirty 队列，再提交模式切换；默认配置为同步模式。

| 规则 | 实现 |
| --- | --- |
| 幂等 | `UNIQUE(resource_id)` + UPSERT（status 不复活） |
| 孤儿清理门控 | `sync_logs.complete` + 合成资源保护（meta.volumes / kind=text_split） |
| 软删除 | `status=deleted`，不物理删除 |
| 快照只追加 | snapshots 不 UPDATE/DELETE |
| 台账隔离 | 桥接状态只存 archive_map |
| SQL 安全 | 全参数绑定，禁 f-string/format 拼值 |
| 容量口径 | `used_space` = SUM(active file size)（NapCat used_space 恒 0 降级） |
| 重启安全 | 迁移幂等 + WAL 崩溃一致性 |
| 数据凋零 | 云侧消失→软删剔除；账号离线群组→隐藏；合成资源保护不变 |
