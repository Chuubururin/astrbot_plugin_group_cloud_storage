# 需求简报

## 一句话定位

**群云存储（Group Cloud Storage）**：QQ 群原生三类存储空间——**群文件**（目录树文件系统）、
**群相册**（图片/视频）、**群精华**（消息存档）——统一建模、索引、检索与转移，构成每个群的云端存储池。

**第一目标**：**多账号群文件统一管理，独立维护元数据支持
增删改查，云（群文件）到云（openlist）的双向桥，存储空间计算与统计，文件格式转换**。
三类空间统一建模为「群云存储池」——云端是唯一数据源，本地只保存可编码化的
元数据索引；文件内容仅在上传、下载、中转、校验时按需流经本机，不持久化本地副本；
一切资源可用稳定 URI（`cloud://<群号>/<类型>/<id>`）引用。

## 存储模型

| 存储空间 | QQ 侧形态 | 本插件建模 | 可管理操作 |
| --- | --- | --- | --- |
| 群文件 | 目录树 + 文件 | 资源类型 `file`（path/ext 文件系统化） | 上传/下载/改名重传/移动/删除/新建目录 |
| 群相册 | 相册 + 媒体 | 资源类型 `album`（meta.album_id 关联） | 上传（图片/分段视频）、媒体查看 |
| 群精华 | 精华消息 | 资源类型 `essence`（长文本分段，meta.parts） | 文本保存、删除、全文重建 |
| OpenList 网盘 | 外部存储 | 桥接双向转存（remote_path 稳定引用） | 浏览/转存/标记/索引 |

> **并列语义**：文件/相册/精华是**并列的资源类别**——文件可存一切；
> 相册只能存图片与视频；精华只能存文字。任何把三者混排为单一列表、以类型筛选区分的设计
> 不符合该语义。

### 设计原则

- **云端是真源（source of truth）**：本地 SQLite 仅保存元数据索引；文件内容只在传输/校验时流经本机，**不持久化本地副本**。
- **一切资源可编码化引用**：`cloud://<群号>/<类型>/<id>`；程序与文档引用资源一律用 URI。
- **本地索引可随时重建**：删库不丢数据，`/cssync` 全量重建；云端删除经对账同步到本地
   （软删 + 合成资源保护）。

### 三条通道（StorageGateway）

| 通道 | 方向 | 用途 |
| --- | --- | --- |
| 云端通道 | OneBot API（NapCat/SnowLuma） | 真源读写：同步、上传、下载直链、精华、相册 |
| 本地通道 | SQLite 索引 + 本机下载服务 | 元数据检索 + 对外 HTTP/SFTP 下载（配置 `download_server_*`） |
| 外部通道 | HTTP/SFTP/SMB | 拉取入库（`/csfetch`）；出库由 OpenList 桥接承担 |

## 目标用户

| 用户 | 诉求 |
| --- | --- |
| 资源池所有者 | 集中管理 300 群、快速检索、容量调度 |
| 外部客户端/程序 | 经 http/sftp/smb 接口读写云端文件 |
| 群成员 | 浏览、下载群资源 |

## 角色与权限（三层）

| 角色 | 层级 | 能力 |
| --- | --- | --- |
| 群成员 | `GROUP_MEMBER` | 本群只读查询 |
| 群管理员（owner/admin） | `GROUP_ADMIN` | 本群管理命令（/cssync /csfiles /csfile…）、文件增删改、精华管理 |
| 全局管理员 | `GLOBAL_ADMIN` | 跨群查询/管理（配置 `global_admin_qqs`） |

授权规则（`PermissionService.can_manage`，同步判定）：目标群须在受管范围
（`managed_groups` **白名单空 = 放行所有群**）；本群操作需 GROUP_ADMIN；跨群需 GLOBAL_ADMIN。
命令处理器不自含权限判断；Page 端走 `is_page_managed`（403 语义）。

## 功能清单（八 Tab 信息架构）

Tab 顺序：【文件】【相册】【精华】【网盘】【任务】【群组】【配置】【调试】。

### 文件

存储符合要求的**任意格式文件**；群文件（云侧）信息扫描；凋零动态更新列表；
操作以 OneBot 11 API 为基准，组合 API 实现各种文件管理操作；文件资源编码化（cloud:// URI）；
文件信息、文件搜索（通过文件名、后缀、上传者、群号、群名、标签等多字段搜索）、文件标签（独立索引/标签，拆分）、
**按类型筛选（13 类分类）与状态筛选**；**大文件集**（>95MB 分卷压缩逐一上传，
列表以语义化大文件名呈现）。

**分类 13 类**：全部 / 文稿 / PDF / 表格 / 幻灯片 / 在线文档 / 图片 / 视频 /
音频 / 压缩包 / 安装包 / 闪传文件 / 文件夹 / 其他；分类后缀支持在配置中编辑
（`type_ext_overrides` 通道，默认表 13 类数据驱动）。**文件夹只有一级**：文件只能在文件夹或
根目录；文件夹单独归为一类（列表目录行恒为「文件夹」类，不参与扩展名判定）。

**状态筛选**：在网盘 / 在相册 / 在精华消息 / 未下载（派生状态，
SELECT 只读不写库；判定以资源 id 关联优先、文件名+大小兜底）。

包括：上传（≤95MB 直传 / >95MB 分卷）、下载（流式/分卷重组）、
改名重传（唯一改名路径）/移动/删除/新建目录、两段式上传、批量操作（删除/移动/标签/直链）、
目录过滤与真面包屑、框选多选、URL 拉取入库（http/https/sftp/smb）、云端大文件转分卷。

### 相册

存储符合要求的**图片和视频**；群相册（云侧）信息扫描；凋零动态更新列表；操作以
OneBot 11 API 为基准；媒体资源编码化；**相册名和描述信息搜索**（独立索引）；**自定义标签
分类与筛选**（相册模块标签表独立，不以统一标签混用）；媒体信息
预览；视频预览 GIF 帧生成；图片预览；**长视频集**（>600s 分片上传，语义化标题翻译为逻辑长视频）。
媒体画廊、长视频分段入库与重组下载。视频上传经协议端能力探测，不可用时明示降级。

### 精华

存储符合要求的**文字**；精华消息（云侧）信息扫描；凋零动态更新列表；操作以
OneBot 11 API 为基准；文本资源编码化；**文本内容搜索**（独立全文索引）；**自定义标签分类
与筛选**（精华模块标签表独立）；**字符统计**；文本预览；**长文本集**
（>4000 字符分片上传，末尾语义化标记整合）；既有能力：文本保存、全文重建（拆分重建/云端取整）、删除。

### 网盘

连接外部 OpenList 存储服务，网盘与群文件**双向传输**（第一目标「云到云桥」的组成）；支持
OpenList 部分管理操作（mkdir/rename/remove/move/copy 等）；**插件自建搜索引擎和标签库**
（独立，不与群内模块共用统一引擎）；文件按类型筛选。

核心能力包括：正向转存（群→网盘，`/csarchive` + WebUI 按钮，零落盘）、反向转存（网盘→群，URL 直传探测，失败自动降级 fetch）、网盘浏览（目录导航、选择、搜索过滤）、幂等去重（archive_map 复合唯一键；stat 探活；远端删除后可重提）、任务驱动轮询（默认手动；有未完成任务才运行，清零自停）、启动恢复（pending/running 行对账）、SSRF 防护（出站校验 + `openlist_allow_private_address` 显式放行）、文件名恢复（UUID → `{filename}` 自动改名）、网盘操作（新建目录/重命名/删除/移动/复制，对齐 OpenList API）、台账单任务查询（`/csbridge status <任务ID>`，未知 ID 返回 unknown）、反向台账联动与收敛（fetch 终态联动台账；孤儿 pending_in 启动收敛为 failed）、网盘索引与标记（netdisk_meta；浏览即登记；深度索引手动任务化）、网盘能力对齐（双数据源适配器；排序/多选/批量/面包屑/chips/分页）、分类与预览可配置（分类数据驱动 + 配置覆盖，改表不改码）。

### 任务

管理正在进行的任务流：**继续、暂停、中断、撤销**已完成或进行中的任务；**撤销任务恢复执行前
状态**；**记录操作流**，操作流同样支持暂停、继续、中断和撤销。定时任务（各种扫描）受管控
（可见/可中断/可暂停调度）；**插件配置功能独立，不在此列**。可逆性口径：删除类云端操作不可逆，明示「不可撤销」。

op_ledger 台账（pending/running/paused/retry/done/failed/cancelled
+ 启动对账白名单续传）、op_ops 操作流（移动/改名/删除/标签埋点）、四动作端点
`tasks`/`tasks/queue`/`tasks/pause`/`tasks/resume`/`tasks/interrupt`/`tasks/undo`/`tasks/ops`
（SSE 含 paused/resumed 事件）；撤销矩阵：排队未执行=丢弃，移动=反向移动，改名=原状恢复，
标签=快照恢复（可翻转），删除类=明示不可撤销。

### 群组

记录符合要求的群信息；**凋零动态更新列表**：在线账号的群组信息才符合要求，
账号离线或更换时该账号群组信息**隐藏**（不删除）；群信息变动经凋零保持更新。操作以
OneBot 11 API 为基准的组合群管理操作。群管理操作：批量改名/加群方式/备注、
自动编号、排序持久化、移除/恢复（白名单优先复活）、账号聚合筛选、框选多选。

### 配置

插件可变参数配置和可选功能参数配置；**归纳分类**分组渲染（8 组：同步与凋零 / 入库与组合
存储 / 桥接与网盘 / 下载服务 / 任务与队列 / 页面与预览 / 权限与发布 / 调试）、**便利优先**
（搜索、变更即时生效提示、危险项二次确认）；配置通道独立于任务体系。
实现：`config/get`（分组 + 敏感脱敏）/ `config/save`（类型归一 + 持久化 + 重载提示）+
配置视图分组渲染。

### 调试

**操作构建器 + API 浏览器 + 调试日志，
三栏同框左中右**。仅配置开关 `debug_workbench_enabled` 开启可用
（默认关闭）+ GLOBAL_ADMIN 语义；限速与 OpQueue 纪律照常；凭据/日志脱敏照常；
不新增监听端口（复用 Page API 通道）。后端 `debug/apis`（自描述 schema：参数类型/必填/枚举/描述）/
`debug/logs`（台账日志）；`debug/exec` 由前端操作构建器经 **`debug/invoke` 统一调用入口**
（{path, params} 直调 Page API，统一 ok/error 包络 + 审计环）承担。

### 硬限制与逻辑资源

| 资源 | 直接上传阈值 | 超限处理 | 逻辑呈现 |
| --- | --- | --- | --- |
| 群文件 | <95MB | >95MB 分片压缩逐一上传（压缩可选、解压可逆） | 文件名语义化翻译为逻辑大文件，入动态列表 |
| 相册视频 | <599s | >600s 无损切割为多个 <599s 分片上传（重压制可选、不可逆） | 语义化标题翻译为逻辑长视频 |
| 精华文本 | <4000 字符 | >4000 按段落/标题/汉字序号分片（每片 ≤4000，含标记预算） | 末尾语义化标记整合为逻辑长文本 |
| 群组 | 在线账号 | 账号离线/更换 → 该账号群组隐藏（凋零，非删除） | 列表仅显示符合要求（在线账号）的群 |

分卷/分片目的：防过期与绕过单条上限；重组经下载后按语义化标识完成；校验卷与压缩为
**可选能力**。

### 缺省规则

- **未选群/账号**：群组未选择时默认选中**全部在线账号与全部群组**；文件、相册、精华
   各自支持查询全部（per-module 筛选状态）；
- **排序**：未选择排序方式时默认**修改时间由新到旧**（`created_at desc`）；
- **分栏**：未选择分栏模式时默认**单栏**（用户显式选择后记忆，双栏能力保留）；
- **上传目标群**：未指定群名/群号时——群文件默认使用**群号值最小且剩余空间大于待上传文件**
   的群；群相册默认群号值最小的群（上限未知）；精华默认群号值最小的群（上限未知）。

### 渲染设计

- 列表符合**文件管理器设计**：提供 `../` 返回上一级（群文件单级文件夹；根目录不显示）；
- 颜色样式风格与 astrbot 原版相同；**同步 astrbot 亮色和暗色模式，支持跟随系统**
   （bridge 上下文 theme 优先，`prefers-color-scheme` 回退）。

| 目标模块 | 本地 | URL 链接 | 网盘 | 群文件 | 相册 | 精华 |

| 群文件上传 | 有（两段式） | 有（fetch 管线） | 有（transfer-in） | — | 图/视频 | 文本 |
| 群相册上传 | 图/视频 | 图/视频 | 图/视频（有损压缩可选） | — | — | — |
| 精华上传 | 浏览器输入文本 | 访问读取文本 | 文档读取 | 文档读取 | — | — |
| 网盘上传 | 文件 | 文件 | — | transfer-out | 图/视频 | 文本 |

> 全部复用既有上传/桥接管线（不新建通道、不新增端口）。跨源入口为真选择器，
> 直接调用目标模块的分发端点；相册 URL 来源含视频；精华网盘文档读取=选择器直通。

### 分类与状态筛选

- 分类机器值：`document/pdf/spreadsheet/slide/online_doc/image/video/audio/archive/
  installer/flash/folder/other`（中文显示由前端字典承担；`program→installer`、`data→other`
  为历史值映射；分类默认表数据驱动，已登记行的 `type` 不重写）；
- 状态筛选派生：`store_status ∈ netdisk|album|essence|none`（在网盘/在相册/在精华消息/未下载；
  资源 id 关联优先，文件名+大小兜底；只读不写库）。

### 下载分发矩阵

以「目标分发」视角统一四模块下载操作（全部经 OpQueue 任务，可见/可中断）：

| 目标 | 文件 | 相册 | 精华 | 网盘 |
| --- | :-: | :-: | :-: | :-: |
| 本地 | 有（流式/重组） | 有（媒体直链） | 有（全文组装） | 有（直链） |
| 直链 http | 有 | 有 | 有 | 有 |
| 直链 sftp | 本机下载服务地址（SFTP 虚拟目录） | 同左 | 同左 | 同左 |
| 直链 smb | 有（需安装 impacket 且配置 `download_smb_port`；未安装时诚实降级提示） | 同左 | 同左 | 同左 |
| 网盘 | 有（bridge-out） | 媒体直链→OpenList 离线任务 | 全文组装→离线任务 | — |
| 相册 | 文件媒体→to_album 任务（云到云） | — | — | 网盘媒体→to_album（D） |
| 精华 | 文本文件→essence_save 任务 | — | — | 网盘文本→to_essence（D） |
| 群文件 | — | 媒体→fetch 入群任务 | 全文→upload 任务 | 有（transfer-in） |
| 浏览器复制 | — | — | 有（essence/text 复制，零落盘） | — |

> 直链转换口径：http（QQ CDN/本机下载服务）→ sftp（本机下载服务虚拟目录）→ smb（需安装 impacket 且配置 `download_smb_port`；未安装时诚实降级提示）。云到云目标
> （相册/精华/网盘/群文件）内容流式，临时产物仅暂存目录、任务终态清理。

### 格式转换

- **转换服务**：视频重封装/重编码（复用 splitter ffmpeg 管线，
  mp4/mkv/webm；重封装优先、重编码兜底）、图片重编码（ffmpeg，不新增第三方依赖）、
  文档→文本（既有解析路径）、文本编码归一（utf-8）；新增 `compress` 有损
  重编码（图片/视频重编码，有损压缩管线，返回新文件不覆写原件）；
- **上传转换**：全部上传操作（files/upload、fetch、相册、精华、网盘）支持 `convert_to`
  目标格式参数；转换并入 OpQueue 任务（可见/可中断），临时产物零落盘；
  本地/相册 URL/URL 入库/网盘分发通道全部接通（fetch 与
  netdisk/distribute 增 convert_to+lossy，text 模式 400 排除）；转换后原临时副本删除、
  文件名扩展名同步修正；
- **UI**：上传来源模态提供格式选项（select：视频 mp4/mkv/webm、图片 png/jpg/webp）；
  媒体处理选项（自动无损切割/有损压缩不可逆警示）。

### 横切能力

一致性对账（云端删除→本地同步，合成资源保护）、容量统计口径、本机下载服务（HTTP/SFTP）、
下载直链、SSE 事件流（30s 心跳/断线自愈）、多账号架构（KeyedLimiter/OpQueue 并行）、
数据规范化（cloud:// URI、path/ext、v_resources 视图、StorageGateway 三通道）、
零 emoji/机器值等工程约束——全部保留。

### 操作规格矩阵

前端操作完整规格。**刷新操作中的"清空"指删除数据库中的指定数据**（本地 SQLite 索引），然后重新从云端拉取。

| Tab | 操作 | 规格条目 |
| --- | --- | --- |
| 群文件 | 上传 | 本地 / URL 链接 / 由网盘 / 由相册（图片视频）/ 由精华（文本） |
| 群文件 | 刷新 | 清空本地重新获取所有群文件信息 / 清空当前选中群重新获取 |
| 群文件 | 分类 | 全部 + 13 类（文稿/PDF/表格/幻灯片/在线文档/图片/视频/音频/压缩包/安装包/闪传文件/文件夹/其他）；分类后缀可在配置中编辑 |
