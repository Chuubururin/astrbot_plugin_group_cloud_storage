# 外部对接指南

> 面向**外部调用方**（外部客户端/程序/LLM 工具链）：如何消费本插件的能力。
> 资源编码口径为 `cloud://<群号>/<类型>/<id>`（稳定引用）与网盘 `remote_path`。

## 外部消费通道一览

| 通道 | 适用 | 入口 |
| --- | --- | --- |
| 聊天指令 | QQ 内人工/脚本触发 | `/cssync` `/csfiles` `/csfile` `/cssave` `/csfetch` `/csarchive` `/csbridge` `/cshelp` |
| 本机下载服务 | 外部 HTTP/SFTP/SMB 客户端直接拉取 | `http://<host>:6186/download?group=<群号>&id=<id>&token=<令牌>`；SFTP 虚拟目录 `/<群号>/<文件名>`；SMB 共享 `cloud`（需配置 `download_smb_port` + impacket） |
| Page REST API | 浏览器/带宿主鉴权的程序 | `files`/`files/uri`/`stat` 等（资源引用用 `cloud://` URI） |
| OpenList 网盘 | 转存后的外部转存 | 经 OpenList 原生接口/MCP（`openlist_dst_dir_template` 决定落盘结构） |

要点：下载直链（QQ CDN 签名 URL）**有时效且不持久化**——外部集成应每次经
插件实时获取，不要缓存 URL；稳定引用一律用 `cloud://` URI 或网盘 `remote_path`。

## MCP：AstrBot 侧能力

| 项 | 结论 |
| --- | --- |
| 角色 | AstrBot 是 **MCP 客户端**（3.5.0+），可添加多个 MCP 服务器并把工具接入 LLM |
| 配置 | WebUI → MCP 设置，录入 `command` + `args` + `env`（如 `uv tool run arxiv-mcp-server`） |
| 前提 | 运行环境需 `uv`（pip 安装）与 `node/npm`（部分 server 需要） |
| 插件侧 | 插件可依赖 `httpx` 自行实现 MCP HTTP 客户端 |

## OpenList MCP Server

### 端点与启用

- 端点：`{SITE_URL}/mcp`（反代子路径则为 `/子路径/mcp`）；默认**关闭**：
  启用配置 `"mcp": { "enable": true }` 或环境变量 `MCP_ENABLE=true`
- 路由：`GET /mcp`（探测，405 + `Allow: POST, DELETE`）、`POST /mcp`、`DELETE /mcp`

### 传输、协议与会话

- **JSON-RPC 2.0 over Streamable HTTP**；`Accept` 必须同时含
  `application/json` 与 `text/event-stream`（否则 406）
- 协议版本 `MCP-Protocol-Version: 2025-11-25`（兼容 2025-06-18）；请求体上限 1MB
- 会话：`initialize` → 响应 `MCP-Session-Id` 头 → 后续必带（TTL 30min，单用户 16，全局 128）

### 认证

- 头 `Authorization`：OpenList 管理 token（恒等比较）或用户 JWT（`ParseToken`）
- 中间件 `Auth(false)`（游客可入）+ `AuthAdmin`（按用户权限校验）

### 工具清单（tools/list）

| 工具 | 参数（必填加粗） | 返回要点 | 用途 |
| --- | --- | --- | --- |
| `openlist.fs.list` | **`path`**，`password?`，`refresh?`，`page?`，`per_page?` | `{content:[{name,size,is_dir,modified,created,sign,thumb,type,hash_info}], total, write, …}` | 目录列表（分页） |
| `openlist.fs.get` | **`path`**，`password?` | 文件/目录详情 | 元数据查询 |
| `openlist.fs.link` | **`path`**，`password?`，`type?` | `{url, url_type, direct_url?, proxy_url?, download_url?}`（签名 `/d` `/p`，含时效） | 下载直链 |

### 错误码（rpcError）

| code | 含义 |
| --- | --- |
| `-32700` / `-32600` / `-32602` / `-32603` | 解析错误 / 非 JSON-RPC 2.0 / 参数无效 / 服务端错误 |
| `-32000` | 协议/会话/流式不符（missing session、版本不支持、Accept 不符） |
| `-32001` | 会话不存在 / 不属于当前用户 / guest 被禁用 |
| `-32003` | 权限不足（密码错误、越权） |


## OpenList 适配的已知边界

**URL 校验是两段式的**（W-3b）：`validate_base_url_structure()` 在**构造时**跑
（纯解析、无 I/O）；DNS 半段（`validate_hostname_dns`）**延迟到首次使用**
（`_ensure_validated()`）。原因是构造函数跑在 AstrBot 的同步插件构造路径上，
阻塞的 `getaddrinfo` 会卡住插件加载。

**TOCTOU**：`adapters/external/base.py` 提供了 `resolve_and_pin_ip()`，
但 **OpenList 的普通 HTTP 请求路径没有 pin IP** —— 校验时解析到的地址与实际连接时
解析到的地址可以是不同的（DNS rebinding）。缓解：`openlist_allow_private_address`
默认 `false`，且只对接自建实例时风险有限。**未修复**，记入待办。

**`mkdir` 的 405 视为"目录已存在"**（REQ-07 幂等契约，`adapters/external/openlist.py`）。
好处是不必先 `stat` 再 `mkdir`；代价是"真的 Method Not Allowed"也会被当成成功。

**`aclose()` 的登出是有界的 best-effort**：只有在**确实存在会话**（`self._token` 非空）时
才发 `/api/auth/logout`，并带显式 5s 超时。没有 token 时跳过 —— 否则
`_request_no_retry` → `ensure_token()` 会在卸载路径上**发起一次登录**
（客户端默认超时 30s），把插件卸载拖住。
