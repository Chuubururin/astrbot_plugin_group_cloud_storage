## 端口契约（六边形唯一出口）

能力协议按 NapCat 分类拆分；适配器同构拆分。

**强制规则**：Adapter 一律返回 DTO（dataclass），禁止裸 JSON 上浮；
core/application 禁止直接 `event.bot.call_action(...)`。

### 能力协议 × 适配器对应

| 模块 | 实现 | 动作 |
| --- | --- | --- |
| CoreCapability | NapCatCoreMixin | get_login_info / get_group_list / send_group_msg |
| GroupCapability | NapCatGroupMixin | get_group_info / get_group_member_list / get_group_member_info / set_group_name / get_essence_msg_list / set_essence_msg / delete_essence_msg |
| GroupExtendsCapability | NapCatGroupExtendsMixin | set_group_add_option / set_group_remark / upload_image_to_qun_album |
| FileCapability | NapCatFileMixin | get_group_root_files / get_group_files_by_folder / get_group_file_url / upload_group_file / delete_group_file / create_group_file_folder / get_group_file_system_info |
| GoCqFileCapability | NapCatGoCqFileMixin | move_group_file |
| AlbumCapability | NapCatAlbumMixin | get_qun_album_list / get_group_album_media_list |

底座 `NapCatBase`：调用通道（多账号绑定）、KeyedLimiter 按账号键控限速、能力探测、
异常分类（LOCAL_ERROR 不重试；资源级错误交 OpQueue 重试）。

## 权限契约

```python
class PermissionLevel(Enum):     # NONE=0 < GROUP_MEMBER=1 < GROUP_ADMIN=2 < GLOBAL_ADMIN=3

class PermissionService:
    def is_managed(self, group_id) -> bool   # 白名单空 → 放行所有群
    def level(self, user_id, role) -> PermissionLevel
    def can_manage(self, user_id, role, target_group, actual_group) -> bool   # 同步方法
    # 1) 目标群不受管 → False  2) 本群 → 需 GROUP_ADMIN+  3) 跨群 → 需 GLOBAL_ADMIN
```

**不存在 `authorize()`**：命令处理器走同步 `permission.can_manage(...)`；
Page 端走 `scan.is_page_managed(group, managed)`（403 语义）。处理器只做
`parse → can_manage → service`。配置：`managed_groups`（留空=全部）、`global_admin_qqs`。

## 命令表

| 命令 | 权限 | 参数 | 语义 |
| --- | --- | --- | --- |
| `/cssync [群号]` | GROUP_ADMIN / GLOBAL_ADMIN(跨群) | 可选群号，默认当前群 | 同步该群云存储索引，返回统计概览 |
| `/csfiles [群号] [页]` | GROUP_ADMIN / GLOBAL_ADMIN | 可选群号/页码 | 分页列出群文件（仅查本地索引） |
| `/csfile <id> [群号]` | GROUP_ADMIN / GLOBAL_ADMIN | id=当前群范围内 `resources.id` | 详情 + 实时下载直链（URL 不持久化） |
| `/cssave [群号] <标题> <正文>` | GROUP_ADMIN / GLOBAL_ADMIN | 正文可含空格 | 文本保存为群精华；超过 `essence_chunk_size` 自动分段 |
| `/csfetch [群号] <URL> [文件名]` | GROUP_ADMIN / GLOBAL_ADMIN | http/https/sftp URL | 拉取外部文件存入群文件（`fetch_max_bytes` 上限） |
| `/csarchive <id> [群号] [force]` | GROUP_ADMIN / GLOBAL_ADMIN | id=资源编号, force=强制重提 | 将群文件转存到 OpenList 网盘 |
| `/csbridge status\|cancel\|retry [任务ID]` | GROUP_ADMIN / GLOBAL_ADMIN | 子命令 + 可选任务ID | 桥接任务管理（status 带任务ID=单任务查询） |
| `/cshelp` | 所有人 | — | 指令帮助 |

> `<id>` 为**当前群范围内 `resources.id`（INTEGER）**，查询恒加 `AND group_id=?` 杜绝跨群泄漏。

## 能力探测与降级

`CapabilityState` 枚举值：UNKNOWN / SUPPORTED / UNSUPPORTED / BROKEN。

探测时机：首次使用某 action；失败进入退避后再探测。群文件三 API 任一 UNSUPPORTED → 全量同步不可用 → 降级仅事件索引 + 可解释告警；get_group_file_url UNSUPPORTED → /csfile 不返回直链，仅元数据；BROKEN → 记录日志并指数退避，不崩溃。桥接侧：OpenList /ping 探测；URL 直传能力键 upload_group_file@url。

## 限速范围

| 项 | 值 |
| --- | --- |
| 限速范围 | **OneBot 扩展 API 请求之间的最小间隔**（递归采集"每文件夹一次请求"） |
| 默认间隔 | **1000ms** |
| 最小间隔 | 100ms（配置下限） |
| 粒度 | 全局间隔器 + KeyedLimiter 按账号键控（跨账号并发互不阻塞） |
| 重试 | 指数退避 1s/2s/4s，上限 3 次 |
| 失败分类 | `Unsupported` / `Timeout` / `RemoteError(RateLimited)` / 其他 |

## OpenList 桥接契约

### archive_map

主键 `(resource_id, group_id, direction)`——remote_path 完成后重命名，不入主键。

### BridgeTaskState 枚举

`pending / running / done / failed / unknown`（机器值）。

### 台账与降级行为

| 行为 | 契约 |
|------|------|
| 单任务查询 | `status(task_id)` 按 task_id 查 archive_map（`get_archive_map_by_task`）；命中 `{task_id, state, direction, group_id, remote_path, updated_at}`，未命中 `{task_id, state: "unknown"}` |
| 反向台账联动 | fetch 回退终态由任务驱动 ledger 消费者联动：队列 done→done，failed/cancelled→failed；无在途任务自停；消费者先于 submit 启动 |
| 僵尸 pending_in 收敛 | 启动恢复将 in 方向 pending/running/unknown 收敛为 failed（fetch 任务不跨重启）；out 方向对账语义不变 |
| URL 直传降级 | 运行期 URL 上传失败 → 能力缓存置 false → 自动回退 fetch 管线，操作不直接失败 |
| 群回执格式 | `send_group_msg` 统一消息链 `[{"type":"text","data":{"text":...}}]` |
| 改名回写 | done 后按大小匹配 UUID 文件并 `/api/fs/rename` 为 `{filename}`，remote_path 回写台账 |

## SSE 事件流

- 端点 `events`（GET，宿主鉴权；前端经 `bridge.subscribeSSE('events', handler)` 订阅，勿用原生 EventSource）。
- 包络 `{type, task_id, kind, state, percent, detail, ts}`；`type ∈ queued|started|progress|done|failed|retry|cancelled|paused|resumed|data_changed|heartbeat`（`paused/resumed` 对应暂停/继续）。
- **任务台账状态机**：`pending → running ⇄ paused → done|failed|cancelled`，重试经 `retry` 中间态；未执行撤销（undo）即 `cancelled`。
- **心跳**：服务端静默期每 30s 发 `{"type":"heartbeat"}`；前端 3×间隔（90s）无事件判定断线，
  指数退避重连（1s→30s 封顶），重连成功触发一次全量刷新。

## 适配器替换成本

- NapCat → Lagrange/SnowLuma：仅新增/调整适配器层，端口契约不变，核心与命令层零改动；
- 持久化实现固定为 SQLite；通过 `MetaStorePort` 隔离存储访问，禁止在业务层引入其他数据库后端；
- OpenList → 其他网盘：仅替换外部适配器层，桥接编排不变。
