# 桥接与网盘设计

## 目标

OpenList 网盘桥接实现 QQ 群文件与 OpenList 网盘的**双向转存**：

- **双向转存**：群文件 ↔ 网盘文件（正向 `/csarchive`、反向网盘视图）
- **零落盘**：正向链路不读取文件字节，只生成直链
- **幂等性**：重复转存自动跳过，远端删除后可重提
- **任务驱动**：异步执行（OpQueue），状态查询/取消/重试
- **安全防护**：SSRF 防护、内网地址控制、密码脱敏
- **网盘模块独立检索**：**插件自建搜索引擎和标签库**（netdisk_meta），
  文件按类型筛选；不与群内模块共用统一引擎

## 架构

```
WebUI / 指令
   └─ BridgeService（桥接编排）
        submit_out（群→网盘）/ submit_in（网盘→群）/ status（台账查询）
        └─ OpenList 适配器
             认证与重登录 / 任务提交 / 目录浏览 / SSRF 防护 / DTO
             └─ OpenList API（/api/auth/login /api/fs/*）
```

分层纪律：入口层不做业务判断；编排层不碰 OneBot 细节与 HTTP 细节；
适配层不做策略，返回 dataclass DTO（OfflineTask/NetFile/DirectLink）。

## 转存流程

### 正向转存（群文件 → 网盘）

- 用户选文件 → 「转存到网盘」→ `bridge/transfer` → `submit_out` 入 OpQueue
- 前置守卫：`dlserver.enabled and http_port > 0`（服务关闭时直链是死链）
- 大小窗口：`bridge_min_bytes`/`bridge_max_bytes`
- 幂等去重：done → 远端 stat 探活（在→跳过；失→清标注重提）；pending/running 直接跳过
- 目标路径：`openlist_dst_dir_template`（`{group_id}/{filename}`）+ 幂等建目录（405 容忍）
- 文件源直链：`get_group_file_url`（仅内存）
- 控制面提交：OpenList 离线下载
- 终态联动：done 后按 size 匹配 UUID 文件并 rename 为 `{filename}`，remote_path 回写；
   发群回执（消息链格式）

### 反向转存（网盘 → 群，handle_bridge_in 自适应）

- 网盘选文件 → 「转存到群」→ `bridge/transfer-in` → `submit_in` 入 OpQueue
- 取 OpenList 直链 → 探测 NapCat URL 直传能力（合成能力键 `upload_group_file@url`）
- 支持 → URL 直传（零落盘）；不支持/运行期失败 → 能力缓存置 false，
   **委托 `ingest.submit_fetch`**（流式写 tmp + 上传后即删 = 全链路唯一落盘点）
- fetch 回退终态由任务驱动 ledger 消费者联动台账；启动恢复将孤儿 pending_in 收敛为 failed

## 安全设计

- **SSRF 防护**：出站仅 http/https；DNS 解析后环回（127/8）、
  私有（10/8、172.16/12、192.168/16）、链路本地（169.254/16）、保留与多播地址一律拒绝；
  `openlist_allow_private_address`（默认 false）显式放行，拒绝信息含开启指引。
- **认证与数据安全**：密码脱敏（config/get 返回 ***）；Token 注入优先；
  401/403 自动重登录并重放一次；反向回退分支流式分块 ≤64KB、禁整文件读入内存、
  临时文件 finally 清理。

## 网盘索引与标记

- `netdisk_meta`（remote_path 主键：tags/type/登记/索引时间）
- **浏览即登记**：`fs/list` 成功后当前目录幂等 `INSERT OR IGNORE`；零常驻任务
- **深度索引**（手动触发）：WebUI 按钮 → kind=`netdisk_index` → 递归逐目录登记
  并回填 `indexed_at`；SSE 进度；可取消，重跑安全
- 标记管理：`netdisk/meta` 覆盖式设置；类型字段用分类字典 + 配置覆盖（改表不改码）
- 模块独立性：网盘检索/标签/类型筛选**独立设计**不变——本表即网盘模块的
  独立索引与标记实现，统一引擎拆除时本模块不受影响

## 指令与 WebUI

| 指令 | 说明 |
| --- | --- |
| `/csarchive <id> [群号] [force]` | 群文件转存到网盘 |
| `/csbridge status [任务ID]` | 任务状态 / 单任务查询 |
| `/csbridge cancel <任务ID>` | 取消任务 |
| `/csbridge retry <任务ID>` | 重试失败任务 |

WebUI：文件管理「网盘」页签（目录导航/面包屑/选择/搜索）；「转存到网盘」「转存到群」；
「设置」在线保存配置（立即生效，密码脱敏）。

**网盘上传入口**：
- **本地上传**（工具栏「上传」）：两步接力——本地文件 prepare/upload 到推荐群 →
  前端轮询任务台账至终态 → 按文件名精确定位资源 → `bridge/transfer`（bridge-out）
  转存网盘根目录；中间群文件副本**明示保留**；
- **URL 上传**：`netdisk/upload-url`（OpenList 离线下载，零落盘）；
- **来源矩阵**（网盘→相册/精华/群文件）：`netdisk/distribute` 目标分发
  （`convert_to`/`lossy` 透传，仅请求时携带）；
- 跨源选择器（文件 Tab「由网盘上传」、相册/精华 Tab「由网盘上传/网盘文档读取」）
  经跨源选择器直调分发端点，零新端点。

## 性能设计

- **任务驱动轮询**：默认手动；自动模式仅在存在未完成任务期间运行、清零自停；
  双列表缺失指数退避 10→30→60s 封顶再 stat 探活；停止时捕获 CancelledError 并写台账终态
- **自动翻页**：per_page≤500，优先 has_more/pages_total，缺字段时回退
- **连接复用**：httpx.AsyncClient 懒建单例、Token 缓存、自动重登录（仅一次）

## 已知限制

- 目录转存不支持（选中目录提示忽略）；超大文件受 OpenList 离线下载器能力限制
- 网盘本地上传为**两步接力**（经群文件中间副本，副本保留）
- smb 直链需安装 impacket 且配置 `download_smb_port`；未安装时诚实降级提示，不伪造链接
- Docker 需 AstrBot 容器与 OpenList 网络互通；`download_server_host` 默认 `127.0.0.1`
  在容器部署下 OpenList 不可达（离线下载报 `dial tcp 127.0.0.1:6186: connect refused`），
  须改为 OpenList 容器内可解析的地址（如宿主容器名 `astrbot`）；
  桥接账号建议关闭 2FA（重登录无 OTP 通道）
