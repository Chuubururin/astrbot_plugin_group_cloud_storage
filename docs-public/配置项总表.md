# 配置项总表

> **唯一口径**：本表提取自 `_conf_schema.json`（32 项 + 分组元数据，与代码一致）。
> 历史上配置曾散落多处且存在漂移（如 `request_interval_ms` 设计草案 500ms，实际默认 **1000ms**）
> ——以本表与 `_conf_schema.json` 为准，其余文档只留指针。
> 修改配置项必须同步本表与 schema（HL-04 纪律）。

## 1. 群与权限

| 配置项 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `managed_groups` | list | `[]` | 受管群白名单；**留空 = 全部已发现群可管理**（订正口径） |
| `global_admin_qqs` | list | `[]` | 跨群全局管理员 QQ（凭据类，不落文档/日志 HL-11） |

## 2. 调度与风控

| 配置项 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `request_interval_ms` | int | `1000` | OneBot 扩展 API 最小间隔（配置下限 100） |
| `auto_scan_interval_hours` | float | `6` | **差分对账周期（已重定义，2026-09-01 W-8，ADR-0006 D-4）**：目录级差分对账的调度周期（小时；0=关闭周期差分，仅事件增补 + 手动全量例外）；定时全量范式已废除 |
| `auto_index_upload_event` | bool | `true` | 监听 group_upload 事件索引 |
| `op_high_priority_kinds` | list | `[]` | OpQueue 优先级 kind 覆盖（空=内置默认） |

## 3. 列表与展示

| 配置项 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `page_size` | int | `10` | 文件列表默认每页条数 |
| `auto_label` | bool | `true` | 自动打标 |

## 4. 入库与拆分

| 配置项 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `essence_chunk_size` | int | `4000` | 精华单条字符上限（**L-3 已落地** 2026-08-31：QQ 实限 4500，预留语义化标记预算，默认 4000） |
| `video_segment_seconds` | int | `599` | 相册视频分段上限（**L-2 已落地** 2026-08-31：>600s 切为 <599s 段，默认 599） |
| `fetch_max_bytes` | int | `2147483648`（2GB） | URL 拉取单文件上限（含桥接回退分支硬限） |
| `fetch_timeout_sec` | int | `180` | URL 拉取超时（秒） |

## 5. 本机下载服务

## 7. 分类与预览（CT-9 改表不改码）

| 配置项 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `type_ext_overrides` | dict | `{}` | 扩展名→类型分类覆盖（影响后续登记/展示，不改已登记行）；**2026-09-01 起分类为 13 类机器值**（document/pdf/spreadsheet/slide/online_doc/image/video/audio/archive/installer/flash/folder/other），后缀编辑即由此配置项承担（N-01） |
| `preview_policy` | dict | `{}` | 预览策略覆盖（mode: builtin/external/download + 外链模板 `{src}`） |

> **13 类分类（2026-09-01，ADR-0008 N-01）**：默认分类表由 `core/domain/file_type.py`
> 重构为 13 类（中文显示前端字典）；`program→installer`、`data→other` 存量映射；目录行
> 恒为 `folder` 类（N-03）；预览策略默认表按新分类组同步。chips 顺序：
> 全部/文稿/PDF/表格/幻灯片/在线文档/图片/视频/音频/压缩包/安装包/闪传文件/文件夹/其他。

## 7.1 调试工作台（T-8/D-8，已实施 2026-08-31）

| 配置项 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `debug_workbench_enabled` | bool | `false` | 调试工作台开关（三栏：操作构建器/API 浏览器/调试日志；默认关闭；仅 GLOBAL_ADMIN 语义） |

> 配置中心分组元数据已内建于 `_conf_schema.json`（`"group"` 字段，8 组：同步与凋零 / 入库与
> 组合存储 / 桥接与网盘 / 下载服务 / 任务与队列 / 页面与预览 / 权限与发布 / 调试）；
> `config/get`（分组 + 敏感脱敏 ***）+ `config/save`（类型归一 + 持久化 + 重载提示）已落地。

## 8. 运维要点

- 配置存放：AstrBot `data/config/`（仪表盘插件配置页编辑）；桥接六项可经页面
  「网盘→设置」在线保存（`bridge/config/save`，密码脱敏返回 ***，保存即生效）；
  全部配置项可经页面「配置」Tab 在线编辑保存（`config/get` + `config/save`）。
- **降级开关**（故障隔离，见回滚预案 §4.1）：`openlist_enabled=false`、
  `download_server_enabled=false`、`auto_scan_interval_hours=0`。
- 禁止在任何文档/日志/测试中出现凭据字面量（HL-11）。
