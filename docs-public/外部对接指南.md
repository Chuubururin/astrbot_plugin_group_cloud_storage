# 外部对接指南

> 面向**外部调用方**（外部客户端/程序/LLM 工具链）与研发：如何消费本插件的能力，
> 以及 OpenList MCP 的核实结论。资源编码口径见数据与编码规范 §1。

## 1. 外部消费通道一览

| 通道 | 适用 | 入口 |
| --- | --- | --- |
| 聊天指令 | QQ 内人工/脚本触发 | `/cssync` `/csfiles` `/csfile` `/cssave` `/csfetch` `/csarchive` `/csbridge`（权限见接口契约 §4） |
| 本机下载服务 | 外部 HTTP/FTP 客户端直接拉取 | `http://<host>:6186/download?group=<群号>&id=<id>&token=<令牌>`；FTP 虚拟目录 `/<群号>/<文件名>` |
| Page REST API | 浏览器/带宿主鉴权的程序 | `files`/`files/uri`/`stat` 等（总表见接口契约 §7；资源引用用 `cloud://` URI） |
| OpenList 网盘 | 转存后的外部分发 | 经 OpenList 原生接口/MCP（`openlist_dst_dir_template` 决定落盘结构） |

要点：下载直链（QQ CDN 签名 URL）**有时效且不持久化**（HL-07）——外部集成应每次经
插件实时获取，不要缓存 URL；稳定引用一律用 `cloud://` URI 或网盘 `remote_path`。

## 2. MCP：AstrBot 侧能力（核实版）

| 项 | 结论 |
| --- | --- |
| 角色 | AstrBot 是 **MCP 客户端**（v3.5.0+），可添加多个 MCP 服务器并把工具接入 LLM |
| 配置 | WebUI → MCP 设置，录入 `command` + `args` + `env`（如 `uv tool run arxiv-mcp-server`） |
| 前提 | 运行环境需 `uv`（pip 安装）与 `node/npm`（部分 server 需要） |
| 插件侧 | 插件可依赖 `httpx` 自行实现 MCP HTTP 客户端（见 §4） |

## 3. OpenList MCP Server（源码核实，2026-08）

### 3.1 端点与启用

- 端点：`{SITE_URL}/mcp`（反代子路径则为 `/子路径/mcp`）；默认**关闭**：
  `config.json` `"mcp": { "enable": true }` 或环境变量 `MCP_ENABLE=true`
- 路由：`GET /mcp`（探测，405 + `Allow: POST, DELETE`）、`POST /mcp`、`DELETE /mcp`

### 3.2 传输、协议与会话

- **JSON-RPC 2.0 over Streamable HTTP**；`Accept` 必须同时含
  `application/json` 与 `text/event-stream`（否则 406）
- 协议版本 `MCP-Protocol-Version: 2025-11-25`（兼容 2025-06-18）；请求体上限 1MB
- 会话：`initialize` → 响应 `MCP-Session-Id` 头 → 后续必带（TTL 30min，单用户 16，全局 128）

### 3.3 认证

- 头 `Authorization`：① OpenList 管理 token（恒等比较）② 用户 JWT（`ParseToken`）
- 中间件 `Auth(false)`（游客可入）+ `AuthAdmin`（按用户权限校验）

### 3.4 工具清单（tools/list）

| 工具 | 参数（必填加粗） | 返回要点 | 用途 |
| --- | --- | --- | --- |
| `openlist.fs.list` | **`path`**，`password?`，`refresh?`，`page?`，`per_page?` | `{content:[{name,size,is_dir,modified,created,sign,thumb,type,hash_info}], total, write, …}` | 目录列表（分页） |
| `openlist.fs.get` | **`path`**，`password?` | 文件/目录详情 | 元数据查询 |
| `openlist.fs.link` | **`path`**，`password?`，`type?` | `{url, url_type, direct_url?, proxy_url?, download_url?}`（签名 `/d` `/p`，含时效） | 下载直链 |

### 3.5 错误码（rpcError）

| code | 含义 |
| --- | --- |
| `-32700` / `-32600` / `-32602` / `-32603` | 解析错误 / 非 JSON-RPC 2.0 / 参数无效 / 服务端错误 |
| `-32000` | 协议/会话/流式不符（missing session、版本不支持、Accept 不符） |
| `-32001` | 会话不存在 / 不属于当前用户 / guest 被禁用 |
| `-32003` | 权限不足（密码错误、越权） |

## 4. 集成方向（规划）

- **方向一（LLM 工具）**：在 AstrBot WebUI 将 OpenList MCP 注册为工具源，让 LLM 直接操作网盘资源
  （对应路线图待办「Skills 封装」）；
- **方向二（插件直连）**：`adapters/link/openlist_mcp.py` 轻量 MCP over HTTP 客户端
  （initialize → tools/call），把 `openlist.fs.link` 作为跨端分发通道（未来 StorageBackend 候选）。
- 统一经端口接入（架构总览 §8 扩展点），不污染 core；新外部调用先落 ADR（HL-05）。
